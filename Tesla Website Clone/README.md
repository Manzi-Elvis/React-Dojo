## Installation

Clone the repository:

```bash
git clone https://github.com/Manzi-Elvis/TESLA-WEBSITE-CLONE.git
```

Move into the project:

```bash
cd TESLA-WEBSITE-CLONE
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
